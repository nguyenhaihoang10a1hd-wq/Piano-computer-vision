#  Virtual Piano – Computer Vision

A virtual piano controlled by hand gestures using a webcam. Built with Python, OpenCV, MediaPipe Hands, NumPy, and Pygame.

### Features

- Real-time hand and fingertip tracking.
- Seven musical notes: Do, Re, Mi, Fa, Sol, La, Si.
- Gesture-based piano key interaction.
- Real-time audio playback and visual feedback.

### Installation

```bash
pip install opencv-python pygame numpy mediapipe==0.10.14
```

### Usage

1. Configure `SOUND_DIR` to your piano sound folder.
2. Run the application:

```bash
python main.py
```

3. Move your fingertips into the virtual piano area to play notes. Press **Q** to exit.
